# 实时竞拍三方接入评审指南

REQ-20261113 · V1.0 · 2026-11-13

基于实时竞拍平台接口与业务答疑形成的三方接入评审页，聚焦接口全景、业务链路、P0 阻塞项、对客确认清单与联调验收门槛。

## 页面能力

- 接口全景与双向能力地图
- 正常成交、收货前退单、收货后差异三条主链路
- 12 个 P0 阻塞项与 13 个 P1 待确认项
- 可直接用于联合评审的确认清单
- 状态机、幂等键与上线验收清单
- 桌面端和移动端适配
- 静态 Markdown 原文可查看

## 发布边界

- 本页为公网脱敏评审版，不包含平台域名、客户名称、联系人、真实订单、金额阈值、访问凭证或密钥。
- 页面为纯静态站点，不连接真实接口、数据库、支付或生产服务。
- 页面设置 `noindex, nofollow`，通过链接访问，不主动进入搜索引擎索引。
- 原始详细指南不会提交到本仓库。

## 本地预览

```bash
cd <本目录>
python3 -m http.server 4182
```

访问 `http://127.0.0.1:4182/`。
